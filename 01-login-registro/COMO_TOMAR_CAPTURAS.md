# Capturas de la aplicación

Abre la dirección local que indica el README y realiza los pasos de su sección final. Usa **Win + Shift + S** para capturar la ventana. Conserva los nombres numerados de `capturas/` si deseas sustituir las imágenes existentes. No captures `.env`, claves ni contraseñas visibles.

Las imágenes incluidas ya son capturas reales. El diagrama MVC es una ilustración explicativa, identificada como tal. Puedes revisar las capturas PNG a tamaño completo sin depender del PDF.
